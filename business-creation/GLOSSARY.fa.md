# واژه‌نامه پایه خلق کسب‌وکار — BC-001

وضعیت: Draft / Pending Review. دامنه: همه انواع کسب‌وکار.

| مفهوم | تعریف عملیاتی | مرز با مفهوم مجاور |
|---|---|---|
| Idea / ایده | تصور یک محصول، خدمت یا روش جدید | ایده به‌تنهایی شواهد تقاضا ندارد |
| Opportunity / فرصت | موقعیتی محتمل برای خلق و کسب ارزش | فرصت هنوز کسب‌وکار اثبات‌شده نیست |
| Customer Segment / بخش مشتری | گروهی با ویژگی یا نیاز مشترک | خریدار، کاربر و ذی‌نفع لزوماً یک نفر نیستند |
| Problem / مسئله | شکاف میان وضعیت موجود و مطلوب | Symptom الزاماً علت ریشه‌ای نیست |
| Customer Job / کار مشتری | پیشرفتی که مشتری می‌خواهد حاصل کند | با ویژگی محصول برابر نیست |
| Pain / درد | مانع، ریسک یا پیامد نامطلوب کار مشتری | با فرضیه راهکار یکی نیست |
| Gain / دستاورد | نتیجه مطلوب و معیار موفقیت مشتری | الزاماً درآمد مستقیم نیست |
| Value Proposition / ارزش پیشنهادی | دلیل ترجیح یک پیشنهاد توسط مشتری | با فهرست قابلیت‌ها فرق دارد |
| Business Model / مدل کسب‌وکار | منطق خلق، ارائه و کسب ارزش | با Business Plan یکسان نیست |
| Lean Canvas / بوم ناب | نقشه فرضیات پرریسک اولیه کسب‌وکار | اعتبارسنجی را جایگزین نمی‌کند |
| Business Model Canvas / بوم مدل کسب‌وکار | نمایش ۹ مؤلفه مدل کسب‌وکار | سند عملیاتی تفصیلی نیست |
| Value Proposition Canvas / بوم ارزش | تناسب کارها، دردها و دستاوردها با پیشنهاد | تمام مدل کسب‌وکار را پوشش نمی‌دهد |
| Customer Journey / سفر مشتری | تجربه مشتری در طول مراحل و نقاط تماس | با جریان داخلی عملیات یکسان نیست |
| Service Blueprint / نقشه خدمت | اتصال تجربه مشتری به فرایندهای جلو و پشت‌صحنه | فقط نقشه سفر نیست |
| Hypothesis / فرضیه | ادعای آزمون‌پذیر درباره واقعیت | ادعای بدون شواهد، حقیقت نیست |
| Evidence / شواهد | داده یا مشاهده با منشأ و محدودیت معلوم | برداشت شخصی بدون ثبت روش، شاهد قوی نیست |
| Experiment / آزمایش | اقدام طراحی‌شده برای آزمون فرضیه | انجام فعالیت به‌تنهایی اعتبارسنجی نیست |
| MVP / محصول حداقلی آزمون | کمینه تجربه/راهکار برای یادگیری از مخاطب | الزاماً نسخه کوچک محصول نهایی نیست |
| Pivot / چرخش | تغییر معنادار فرضیه/راهبرد بر پایه یادگیری | با تغییر ظاهری یا فیچر یکی نیست |
| Feasibility / امکان‌سنجی | بررسی امکان فنی، عملیاتی، مالی، حقوقی و بازار | با مطلوب‌بودن اقتصادی یکسان نیست |
| Viability / پایداری اقتصادی | امکان دوام مدل در شرایط واقعی | صرفاً امکان ساخت نیست |
| Business Case / توجیه کسب‌وکار | مقایسه گزینه‌ها، منافع، هزینه‌ها و ریسک برای تصمیم | با کل طرح کسب‌وکار یکسان نیست |
| Business Plan / طرح کسب‌وکار | برنامه اجرای مدل و راهبرد با اهداف و منابع | با بوم یک‌صفحه‌ای فرق دارد |
| Business Structure / ساختار کسب‌وکار | چیدمان مالکیت، شخصیت حقوقی و سازمان | فقط چارت سازمانی نیست |
| Operating Model / مدل عملیاتی | نحوه ارائه ارزش با افراد، فرایند، فناوری و حکمرانی | از مدل درآمدی جزئی‌تر است |
| Business Architecture / معماری کسب‌وکار | نمایش قابلیت‌ها، جریان‌های ارزش، سازمان و اطلاعات | صرفاً معماری نرم‌افزار نیست |
| Unit Economics / اقتصاد واحد | درآمد و هزینه نسبت به واحد اقتصادی تعریف‌شده | با سود کل و جریان نقدی برابر نیست |
| GTM / ورود به بازار | شیوه دستیابی، فروش و ارائه ارزش به مشتری | با تبلیغات تنها برابر نیست |
| Product-Market Fit / تناسب محصول و بازار | شواهد تقاضای تکرارشونده و رضایت بازار هدف | یک شاخص واحد جهانی ندارد |
| Decision Gate / گیت تصمیم | نقطه بررسی شواهد برای ادامه/اصلاح/توقف | به معنی تأیید خودکار نیست |

## نگاشت
۱۲ دامنه و ۸ مسیر تخصصی در README و SPECIALIZATIONS تعریف شده‌اند؛ این واژه‌نامه واژگان مشترک آن‌هاست. تعاریف عملیاتی پیشنهادی‌اند و برای انتشار آموزشی باید با منابع اصلی و بازبین تخصصی تطبیق شوند.
