# واژه‌نامه فارسی نیک‌وی

**نسخه:** ۱.۰.۰  
**وضعیت:** پیشنهادی

این واژه‌نامه، برابرهای ترجیحی را مشخص می‌کند. نام رسمی فناوری‌ها و استانداردها همچنان به شکل اصلی نوشته می‌شود.

| واژه اصلی | برابر ترجیحی فارسی | توضیح کوتاه |
|---|---|---|
| Identity | هویت | آنچه موجودیت را مشخص و متمایز می‌کند |
| Context | زمینه | شرایط و روابط مؤثر در معنا |
| Purpose | هدف وجودی | دلیل و مقصود وجود سیستم |
| Observer | ناظر | کسی یا چیزی که مشاهده می‌کند |
| Observation | مشاهده | دریافت و ثبت اطلاعات |
| Distinction | تمایز | تشخیص تفاوت |
| Entity | موجودیت | چیزی که درباره آن سخن می‌گوییم |
| Relationship | رابطه | پیوند میان موجودیت‌ها |
| Model | مدل | بازنمایی هدفمند یک موضوع |
| Kernel | هسته | سازوکارهای بنیادی سیستم |
| System | سیستم یا سامانه | اجزای مرتبط که کلیتی را شکل می‌دهند |
| Loop | حلقه | رابطه یا فرایند بازگشتی |
| Feedback | بازخورد | اطلاعات برگشتی درباره نتیجه |
| Decision | تصمیم | انتخاب از میان گزینه‌ها |
| Evidence | شواهد | اطلاعات پشتیبان یک ادعا |
| Framework | چارچوب | ساختار سامان‌دهنده کار |
| Methodology | روش‌شناسی | منطق و مجموعه روش‌های انجام کار |
| Playbook | راهنمای عملی | شیوه انجام کار در موقعیت مشخص |
| Handbook | راهنمای جامع | مجموعه اطلاعات و راهنماهای مرجع |
| Repository | مخزن | محل نگهداری فایل‌ها و تاریخچه |
| Commit | ثبت تغییر | ثبت نسخه‌ای از تغییرات در گیت |
| Branch | شاخه | مسیر مستقل تغییرات |
| Pull Request | درخواست بررسی و ادغام | پیشنهاد بررسی تغییرات یک شاخه |
| Merge | ادغام | ترکیب تغییرات |
| Release | نسخه منتشرشده | نسخه مشخص و ارائه‌شده |
| Journal | دفتر وقایع | ثبت زمان‌مند رخدادها |
| Living Book | کتاب زنده | کتابی که با شواهد و تجربه تکامل می‌یابد |
| Local-first | آغاز کار به‌صورت محلی | انجام کار اصلی روی رایانه خود و همگام‌سازی بعدی |

## قاعده تغییر واژه
تغییر برابر ترجیحی باید همراه با دلیل، تاریخ و بررسی اثر آن بر اسناد ثبت شود. برابرهای قبلی در تاریخچه حفظ می‌شوند.
