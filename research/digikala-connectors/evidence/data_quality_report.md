# گزارش کیفیت و پوشش داده

- mmdju/digikala-mcp: اسکریپت عمومی verify-live در ۱۵ نوامبر ۲۰۲۶ handshake نسخه ۰٫۹٫۲، فهرست ۱۹ ابزار، جست‌وجوی سه قلم، قیمت تومانی و URL محصول را گزارش کرد. فرایند در مهلت ۲۰ ثانیه پیش از پایان آزمون‌های بعدی متوقف شد؛ PASS فقط برای همان مسیرهای مشاهده‌شده است.
- upstream مستقیم api.digikala.com/v1/search/ با درخواست عمومی نمونه HTTP 404 داد. این نتیجه فقط پایداری آن مسیر خاص را نشان می‌دهد و مجوز تلاش برای دورزدن نیست.
- sepehr071/digikala-mcp: کد Python با compileall بدون خطا کامپایل شد. تست‌های pytest اجرا نشدند چون pytest در محیط پایه نصب نبود؛ PASS تست واحد ادعا نمی‌شود.
- ruhollah82/digikala_dataset: گزارش مجموعه ۲۳۷٬۸۵۵ ردیف را اعلام می‌کند. این آمار خوداظهاری فایل است و به‌عنوان آمار جاری دیجی‌کالا استفاده نمی‌شود.

داده زنده mmdju برای نمونه‌برداری محدود قابل ردیابی است، اما وابستگی به سرویس میزبانی‌شده، API مستندنشده و محدودیت ۲۰ درخواست در دقیقه دارد. sepehr از نظر قابلیت بازبینی کد و مجوز MIT مناسب‌تر است، ولی باید در sandbox، با ثبت hash پاسخ، زمان دریافت، سقف نرخ و fail-closed اجرا شود. dataset فقط شاهد ثانویه تاریخی/زبانی است.
